# ADR 004: Automação de Testes de Aceite via Parseamento de Output

Status: Aceito

Contexto:
O projeto exige a validação formal através de 6 testes de conectividade e segurança (ping, isolamento de CFTV, obtenção de DHCP). Não queremos adicionar nós pesados (como VMs Linux inteiras) apenas para rodar testes.

Decisão:
Utilizaremos os próprios VPCS (Virtual PC Simulator) nativos do GNS3 para disparar os testes. O Python acessará o console do VPCS via Netmiko, enviará o comando ping e fará o parsing textual da resposta (timeout, unreachable ou respostas válidas) para determinar o Pass/Fail do teste.

Consequências:

Positivo: Mantém a topologia extremamente leve, consumindo pouca RAM do servidor. Representa fielmente a experiência do equipamento final da topologia.

Negativo: Testes baseados em parseamento de string (Screen Scraping) podem ser frágeis caso a formatação de saída do VPCS mude em atualizações futuras do GNS3.
