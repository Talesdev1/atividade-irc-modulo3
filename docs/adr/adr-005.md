# ADR 005: Gestão de Credenciais e Variáveis de Ambiente

Status: Aceito

Contexto: Evitar a exposição de senhas de acesso aos equipamentos de rede (enable password, admin password) e o IP interno do servidor GNS3 no código fonte.

Decisão: Adotar a biblioteca python-dotenv. Todas as credenciais, portas base de console e a URL da API do GNS3 serão armazenadas em um arquivo .env local, que será ignorado pelo controle de versão (via .gitignore).

Consequências:

Positivo: Aumenta a segurança e facilita a portabilidade do projeto (cada desenvolvedor pode ter um .env apontando para o seu próprio GNS3 Server).

Negativo: Adiciona um passo extra no setup inicial (necessidade de criar o arquivo .env manualmente a partir de um .env.example).
