# ADR 003: Estratégia de Idempotência "Read-Before-Write"

Status: Aceito

Contexto:
Os scripts de automação podem ser executados múltiplas vezes. Executar um comando de criação de nó cego (blind write) no GNS3 gerará equipamentos duplicados ou erros na API.

Decisão:
Implementar um padrão obrigatório de "Read-Before-Write" (Ler antes de Escrever). Antes de qualquer requisição POST para criar um projeto, nó ou link, o script fará um GET para verificar se o recurso já existe. O mesmo se aplica ao Netmiko (ex: verificar via show vlan se a VLAN existe antes de tentar criá-la).

Consequências:

Positivo: Previne a quebra do laboratório e corrupção da base de dados do projeto GNS3. Permite reexecutar o script com segurança.

Negativo: Aumenta a verbosidade do código e o tempo de execução (devido às chamadas de rede adicionais para validação).
