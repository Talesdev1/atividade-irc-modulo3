# ADR 002: Injeção de Configurações com Netmiko e Jinja2

Status: Aceito

Contexto:
Após a criação da infraestrutura, é necessário aplicar configurações L2/L3 (VLANs, DHCP, Roteamento) nos switches Extreme EXOS e endereçamento IP nos VPCS via terminal (Console/Telnet/SSH).

Decisão:
Utilizaremos Netmiko para estabelecer as conexões com as portas de console e injetar comandos. Para evitar código hardcoded, usaremos Jinja2 para gerar as configurações finais a partir de templates estruturados.

Consequências:

Positivo: Netmiko lida nativamente com o prompt e as peculiaridades dos equipamentos de rede (inclusive tratamento de paginação). Jinja2 permite separar os dados (plano de IPs) da sintaxe EXOS.

Negativo: Dependência de acesso via Telnet local (porta de console do GNS3) durante o provisionamento inicial, o que requer mapeamento cuidadoso das portas expostas pelo servidor GNS3.
