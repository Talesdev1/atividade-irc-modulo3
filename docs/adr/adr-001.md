# ADR 001: Uso de Python com gns3fy para Orquestração da Topologia

Status: Aceito

Contexto:
Precisamos provisionar nós (switches, PCs) e links de forma 100% automatizada no GNS3. Ferramentas puramente declarativas como Terraform possuem provedores limitados ou desatualizados para GNS3, dificultando o suporte a nós específicos como VPCS ou appliances EXOS customizados.

Decisão:
Utilizaremos scripts em Python com a biblioteca gns3fy (e chamadas diretas via requests à API REST do GNS3 quando necessário).

Consequências:

Positivo: Flexibilidade total para manipular qualquer endpoint da API do GNS3. Integração natural com o agente de IA (OpenCode), que tem facilidade em gerar e debugar Python.

Negativo: Como não há um "arquivo de estado" nativo (state file como no Terraform), a lógica de idempotência precisará ser implementada manualmente nos scripts.
